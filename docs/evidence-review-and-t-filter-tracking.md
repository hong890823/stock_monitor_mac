# 证据复核与冲高做 T 观察记录

日期：2026-10-14

## 已落地

- 盘中强势环境继续由确定性规则判断，量能、指数和板块同时偏强时暂缓机械做 T。
- 持仓报告增加市场证据卡，以及支持证据、反向证据、尚缺信息和判断失效条件。
- 暂缓做 T 事件保存触发价、当前价、观察状态、观察区间最高/最低变化和可取得的第 1/3/5 个交易日价格。
- 旧 JSON 缓存字段保持兼容；新增字段均为可选或有默认值。

## 口径边界

- 全天预估成交额沿用现有预测，不新增第二套算法。
- 2 万亿只是高活跃度观察线，不单独等于良性行情；仍需结合指数位置、板块扩散和完整收盘日量能。
- 单日高量与持续高量分开表达，今日预估不计入历史连续性。
- 缺失/过期数据只显示暂缺/已过期，不猜测方向。
- 跌破支撑等风险信号始终优先。
