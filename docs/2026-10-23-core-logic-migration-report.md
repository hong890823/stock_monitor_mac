# Stock Monitor 核心逻辑迁移验证报告

## 结论

本轮已完成今日要闻、东财涨跌停池、封板质量、资金流证据、候选状态机、晋级环境过滤、观察池版本3迁移、分组展示和历史晋级指标。实现继续遵守资金流只作辅助证据、封板期间不普通买入、缺失数据中性、A股 T+1 和“晋级不等于下单”的边界。

历史样本没有提供足够证据支持修改现有阈值：突破候选在该样本中的前瞻表现偏弱，且回测中的 `BREAKOUT` 记录没有产生 `can_buy` 晋级；回踩候选的收益接近基准。因此保留文档中的既有阈值，不把结果解释为收益保证。

## 回测口径

- 命令：`python3 backtest_entry_structure.py --samples 300 --seed 42 --out /tmp/stock-monitor-backtest-2026-10-23.json`
- 对比：`python3 backtest_compare.py /tmp/stock-monitor-backtest-2026-10-23.json`
- 股票数：300；随机种子：42；判态次数：282,856。
- 样本区间：2022-07-12 至 2026-08-25。
- 行情提供方在本次运行时不可用，因此按相同种子从本地已有日线缓存的 851 只样本中抽取 300 只；缓存行数不足 60 的代码被排除。
- `eligible` 表示状态为突破或回踩、趋势未转弱且大盘数据未明确失败的日线记录；`miss_rate = eligible_not_promoted / eligible`。
- `max_drawdown_5d` 为该组所有记录从信号收盘到未来5个交易日收盘路径的最大峰谷回撤中的最大值。

- 突破状态在 10 日维度的胜率为 40.9%、平均收益为 -0.59%，相对基准分别低 6.9 和 1.03 个百分点。

## 风险与限制

- 样本只包含当前缓存中的在市股票，存在生存偏差；结果更接近历史上界，不代表可交易结果。
- 回测不含佣金、印花税、滑点、涨跌停无法成交、流动性和实际排队成交。
- 三个策略状态共享 2022-07 至 2026-08 市场环境，跨周期稳定性尚未得到独立样本验证。
- 最大回撤取组内极值，会受单只极端行情影响；调参时应同时查看分位数和分年度结果。
- `BUY_CANDIDATE`、买点提醒、今日要闻和资金流证据都不构成自动下单、收益承诺或投资建议。
