# 盘中风险与量价上下文项目归档

> 状态：已实现并通过测试  
> 适用范围：A股 T+1 持仓监控、盘中风险提醒、分批减仓与买入确认  
> 用途：作为其他项目改造盘中提醒策略的需求、设计和验收依据

## 一、改造目标

盘中提醒不能只看“当前价格跌破某个固定位置”，也不能只凭成交量直接决定买入或清仓。系统应同时使用：

1. **日级慢变量**：历史价格位置、趋势、事件风险、组合风险、持仓风险等，按交易日缓存。
2. **盘中快变量**：15/30分钟K线、个股量比、当前15分钟量能、两市成交额、下杀承接和冲高回落形态。
3. **交易资格**：交易账本、A股T+1、当日可卖批次和账本一致性。

量价和历史上下文负责调节确认强度、动作力度和风险刹车，不单独构成未经确认的买卖指令。

## 二、总体架构

```text
日线/趋势/持仓分析
        │
        ▼
DailyRiskContextCache ──────┐
                            │
实时行情 + 15/30分钟K线 ────┼──> TimeframeEvidence
两市成交额 + 个股量比 ──────┘            │
                                         ▼
                              evaluate_trade_action
                                         │
                                         ▼
                              统一动作守卫 / T+1账本
                                         │
                                         ▼
                                  盘中提醒文案
```

参考实现模块：

- 日级上下文：`daily_risk_context.py`
- 盘中量价上下文：`intraday_volume_context.py`
- 15/30分钟证据：`intraday_bars.py`
- 确定性动作：`intraday_trade_policy.py`
- 统一动作守卫：`trade_action_guard.py`
- T+1批次账本：`trade_ledger.py`
- 盘中链路组装：`stock_menubar.py`

## 三、日级上下文

### 3.1 缓存规则

- 缓存键：`(股票代码, 行情交易日)`。
- 同一交易日只构建一次，15秒盘中轮询只读取快照。
- 日报日期与行情交易日期不一致时，不复用旧日报的系统性风险。
- 不在盘中轮询中重新抓取日线或重算完整技术指标。

### 3.2 字段

| 字段 | 含义 | 主要用途 |
|---|---|---|
| `source_date` | 日级上下文所属交易日 | 防止跨日污染 |
| `price_location` | 60日价格位置 | 低位/高位风险 |
| `range_low` | 近期区间低点 | 创新低和结构失效 |
| `invalidation_price` | 结构失效价 | 极端风险 |
| `major_trend` | 主趋势 | 趋势风险 |
| `five_day_no_new_low` | 近5日是否未创新低 | 下行结构 |
| `closes_below_ma20` | 连续跌破M20天数 | 趋势转弱 |
| `high_exit_risk` | 高位且趋势走坏/派发 | 清仓通道 |
| `systemic_risk` | 持仓普遍下跌等系统性信号 | 清仓通道 |
| `portfolio_risk` | 半数以上持仓破位或转弱 | 组合风险 |
| `event_risk` | 基本面或公告红灯 | 清仓通道 |
| `position_risk` | 仓位成本占比超过10% | 动作门槛 |
| `liquidity_risk` | 流动性风险 | 预留动作规模调节 |

### 3.3 风险级别

- `NORMAL`：普通破位。
- `ELEVATED`：低位、大趋势向下、连续跌破M20等历史风险。
- `CRITICAL`：高位派发、事件风险、组合风险、系统性风险，或跌破失效价/创出新低。

## 四、盘中量价上下文

### 4.1 两市成交量

```text
market_turnover_ratio = 当前预计全天成交额 / 近5个完整交易日成交额中位数
```

- `market_turnover_ratio >= 1.2`：两市放量。
- 预计成交额或历史基线缺失：量能证据不足。
- 该指标是成交活跃度代理，不等同于主力净流入或“大资金入场”。

### 4.2 个股量能

个股累计量比沿用按交易时间折算的统一口径：

```text
stock_volume_ratio = 今日累计成交量按已交易时间折算 / 20日均量
stock_volume_confirming = stock_volume_ratio >= 1.3
```

同时计算当前15分钟K线量能：

```text
bar_volume_ratio = 最新15分钟成交量 / 前20根15分钟成交量中位数
bar_volume_confirming = bar_volume_ratio >= 1.3
```

下杀承接和冲高回落判断优先使用当前15分钟量能；累计量比只能作为历史回退，不能覆盖当前K线量能不足的事实。

### 4.3 量价形态

#### 上涨放量

- 个股量能确认；
- 两市成交量放大；
- 15/30分钟结构站稳；
- 没有明显上影拒绝或冲高回落。

满足后才允许小仓买入确认。上涨缩量、两市缩量或放量冲高回落时降级为观察。

#### 冲高回落风险

同时满足：

- 当前上涨；
- 当前15分钟量能确认；
- 上影线占振幅至少50%；
- 收盘低于K线中点。

此时停止追涨，不把放量视为买入确认。

#### 下杀承接

同时满足：

- 现价和最新15分钟收盘跌破支撑；
- 下影线占振幅至少35%；
- 收盘收复K线中点；
- 收盘接近前一根15分钟收盘；
- 当前15分钟量能确认。

该形态只表示承接迹象，首批卖出压到100股并继续观察，不直接表述为确定的“大资金入场”。

## 五、破位阈值与确认

```text
risk_threshold_pct = clamp(0.5 × ATR15 / support, 0.5%, 1.5%)
risk_price_threshold = support × (1 - risk_threshold_pct)
```

- `risk_confirmations` 只统计连续低于风险阈值的已完成15分钟K线，最多统计3根。
- 单根破位：只报告风险。
- 两根确认：进入首批减仓评估。
- 三根确认：只有 `CRITICAL` 才允许分批离场剩余可卖仓位。

## 六、动作矩阵

| 场景 | 动作 |
|---|---|
| 单根破位 | 等待确认，不卖出 |
| 两根确认、普通/偏高风险 | 首批最多约1/3可卖，按100股向下取整 |
| 两根确认、出现下杀承接 | 首批最多100股，继续观察是否收复支撑 |
| 三根确认、`CRITICAL` | 可分批离场剩余当日可卖仓位 |
| 三根确认、非`CRITICAL` | 继续分批，不自动清仓 |
| 当日无可卖批次 | 只记录风险，下一交易日处置 |
| 买入证据或量能不足 | 仅观察，不执行买入 |
| 账本数量不一致 | 阻断可卖股数 |

## 七、失败安全

- 行情日期缺失或无效：不生成确定性买卖。
- K线不是当前交易日最新已完成槽位：只能观察。
- 15/30分钟证据缺失：不能买入、卖出或做T。
- 量能证据缺失：买入降级为观察；风险卖出不能被放量单独豁免。
- 日级上下文缺失：不得伪造高风险，也不得自动清仓。
- 流动性数据缺失：不强行放大卖出数量。
- 账本数量不一致：`actionable_sellable_quantity = 0`。
- 所有入口先生成结构化意图，再经过统一动作守卫；AI文案不能绕过本地规则。

## 八、审查结论与修复记录

本次审查未发现需要立即回滚的阻断性问题。审查中已修正：

1. 下杀承接原先可能只看累计量比，现已优先使用当前15分钟K线量能。
2. 个股量能或两市成交额缺失时，买入原先可能放行，现已降级为观察。
3. “仅观察”的买入判断原先可能被文案守卫重新放行，现已统一拦截。
4. 日报日期与行情日期不一致时，不再把旧的系统性风险快照带入新交易日。

## 九、已知边界

- 两市成交额只能衡量市场活跃度，不能证明主力净流入。
- 下杀放量既可能是承接，也可能是派发；必须结合下影线、收复中点和后续止跌。
- `liquidity_risk` 当前已接入上下文，但尚未独立改变卖出数量。
- 历史导入仓位的买入日期可能未知，T+1可卖数量依赖账本日期质量。
- 开盘前几根15分钟K线的历史量能基线较短，应继续通过双周期和连续确认降低噪声。

## 十、其他项目迁移清单

- [ ] 行情交易日期使用数据源交易日，不使用本机自然日期。
- [ ] 日级上下文按交易日缓存，禁止每15秒重算。
- [ ] 15分钟K线只接受最新已完成槽位。
- [ ] 同时提供累计量比和当前15分钟量比。
- [ ] 两市成交量使用同口径基线，不用盘中累计额直接对比历史全天额。
- [ ] 单根破位不执行卖出。
- [ ] 量能缺失时买入失败安全。
- [ ] 下杀承接只能缩小首批卖出，不能自动等同于买入。
- [ ] `CRITICAL` 风险保留清仓通道。
- [ ] 所有卖出数量受T+1和账本一致性约束。
- [ ] 所有最终文案经过统一动作守卫。

## 十一、验收标准

- 单根破位不会卖出。
- 两根确认只允许首批减仓。
- 下杀承接会把首批压到100股。
- 当前15分钟量能不足时，不判定下杀承接。
- 高位、事件、组合或系统性风险不会被量价承接完全取消。
- 上涨缩量、两市缩量、冲高回落不能触发买入。
- 量能数据缺失时买入输出“仅观察”。
- 账本不一致时不能生成可卖数量。
- 日级上下文按交易日缓存，跨日不复用。
- 所有缺失数据最终输出为观察、风险事实或下一交易日处置。
