# 成交额环境质量与冲高做T策略

> 对应代码：`market_environment.py`、`intraday_tactics.py`、`stock_menubar.py`、
> `portfolio_daily_report.py`；Android 对应 `MarketEnvironmentQuality.kt`、
> `IntradayTactics.kt`、`MonitorService.kt`、`MarketSummary.kt`。

## 核心判断

两市全天预估成交额达到 2 万亿，说明交易活跃，但不能单独推出“后续上涨动能仍足”。
同样的高成交额，可能是增量资金推动的良性放量，也可能是高位换手、指数滞涨和板块分歧。
因此策略把成交额放在环境质量模型中，与连续性、指数位置和板块宽度一起解释。

## 环境等级

| 等级 | 主要条件 | 对冲高做T的影响 |
|---|---|---|
| 强势延续 | 今日预估成交额 >= 20000 亿；此前完整收盘日最近 3 日每天 >= 17000 亿且三日均值 >= 18000 亿；行业、概念宽度均 >= 60%；沪指不跌且距日高 < 1% | 放量冲高暂不主动做T，提示等待延续 |
| 高成交额待确认 | 高成交额、指数和板块宽度支持，但连续性不足 | 谨慎观察，不把单日脉冲视为趋势确认 |
| 放量分歧 | 高成交额且已观测到指数滞涨或板块扩散不足 | 恢复普通冲高做T提醒 |
| 普通环境 | 未达到高量级阈值 | 沿用原有个股冲高做T规则 |
| 数据不足 | 关键数据缺失或异常，包括预估成交额、指数位置或板块宽度 | 不把缺数据说成分歧或利好，沿用原有个股规则 |

## 证据与文案

程序只输出实际拿到的证据：今日预估成交额、此前完整收盘日的连续高量天数与最近三日均值、沪指涨跌及日内位置、行业/概念板块上涨占比、个股和所属板块状态。今日预估不会被计入连续性，必须等收盘数据落盘后才可成为后续交易日的完整收盘证据。
北向、两融、IPO、减持等数据没有接入时，不会被自动写成利好或利空；板块宽度也不冒充全市场个股上涨家数。

提醒和报告采用动态状态与证据拼接，不使用固定“行情一定继续上涨”的话术：

- 充分确认时写“强势延续观察”，保留继续拉升的可能性，但不承诺上涨；
- 只有单日高量时写“高成交额待确认”；
- 放量但指数或宽度不配合时写“放量分歧”，恢复做T风险提示；
- 关键证据缺失时标为“数据不足”，沿用原有个股规则，不将缺失描述成已经观测到的分歧；
- 跌破支撑等风险信号始终优先。

## 跨端对齐与限制

macOS 版和 Android 版共用相同阈值、等级和降级原则。macOS 版额外按信号置信度动态决定确认轮数；Android 版沿用固定确认轮数。
两端都使用程序已有的全天预估成交额与成交额历史，不新增第二套预测算法。

该策略是条件式提醒，不是自动交易策略，也不构成投资建议。高成交额环境只能降低“单日天量直接做T”的误判，不能保证后续继续上涨。

## 执行边界

环境等级只决定是否放大、暂缓或恢复冲高做T候选，不直接产生交易指令。最终文案仍须通过`trade_action_guard.py`：普通做T要求新鲜的15/30分钟共同确认、行情交易日期有效，并且数量不超过交易账本当交易日的可卖批次；当日买入仓位受T+1限制。证据不全或当日无可卖仓位时，只输出观察、风险事实或下一交易日复核。
