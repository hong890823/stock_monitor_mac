# 选股持续观察池

## UI 买点标识

「选股」一级菜单按当前晋级状态从高到低平铺：**🎯 已晋级／买点已确认 → 🟡 日线候选／等待确认 → ⚪ 持续观察 → 📋 今日提醒记录**。历史提醒明确标注“非当前买点”，严格、宽松、513 原始扫描结果放在操作入口之后。每组最多展示 8 只并保留总数，候选股票不再藏在“🔎 持续观察池”子菜单里。这是状态与历史记录展示，不是实时可买列表。

晋级链路为 `OBSERVING → NEAR_ENTRY → BUY_CANDIDATE`，异常状态为 `ELIMINATED`。普通候选通常在 15–45 分钟内完成 2 轮确认，连板数大于等于 3 时需要 3 轮，封板会使确认轮次清零。`BUY_CANDIDATE` 只代表观察晋级，不代表自动下单。

| 标识 | 含义 |
|---|---|
| 📋 今日曾提醒·非当前买点 | 当前观察轮次在今天成功发送过提醒；显示当时的触发时间、价格、失效参考，不表示现在可以买。记录不受单策略 30 行限制 |
| 🟡 日线候选·等待回踩确认 | 日线复核已就绪，仍需盘中回踩和承接确认；封板、开板本身都不算买点 |
| ⚪ 观察中／筛选命中·未确认 | 仍在观察，或仅有选股命中，未达到上述状态 |
| ⚠️ 待复核／已淘汰／观察到期 | 当前资料待核对或已退出；即使今天曾提醒，也移出顶部提醒计数，并提示重新确认 |

今日标识随日期切换自动清除，必须匹配股票与当前观察轮次，不能由昨天、未来时间或旧轮次的提醒产生。标记说明的是“今日曾发送提醒”，**不是当前仍然满足买入条件**。顶栏使用提醒时价格；原策略列表的价格仍是选股数据中的价格。

右上方替代窗口显示「📋 今日曾提醒N只（非当前买点）」，并可展开当前菜单查看完整名单。历史提醒行用灰色，候选用蓝色配黄色图标，观察状态用灰色；菜单栏与替代窗口使用相同图标和文字。

候选预览最多列 8 只，其余可在观察池明细查看；今日提醒记录全部集中列出。同一股票命中多套策略时，顶部名单只计一次。

每次成功扫描产生的严格、宽松、513 新命中自动进入观察池。同一股票只建立一条当前记录，保留多个入池来源；继续持有在观察池中的股票会单独取得日线复核，不依赖再次入选或留在成交前 200 名。

## 使用入口

菜单栏「选股」直接提供「立即复核观察池」和「查看完整观察报告」，不再增加持续观察池二级菜单。完整报告按已晋级、日线候选、持续观察、已淘汰、观察到期展开，展示入池日期、完整交易日计数、复核收盘价、数据日期、条件满足项数及阶段变化原因。历史提醒明确标注「当时触发价」。完整报告附每日复核价格与判断记录。

成功选股后立即复核；已入池股票另外在工作日 15:10 后自动复核，午夜至 06:00 可补做。成功后等待下一次盘后，失败或数据暂缺时 90 分钟后重试。应用需要保持运行；重启后恢复记录，并利用已有日线补做入池后的复核。

## 状态规则

| 状态 | 条件 |
| --- | --- |
| 继续观察 | 新入池、未满两个完整交易日，或当前未出现有效入场结构 |
| 日线候选 | 至少两个完整交易日，日线 `entry_structure` 的 `can_buy` 为真，且同日上证指数收盘位于其 M20 上方或等于 M20；仍需盘中确认 |
| 已淘汰 | 连续两个完整交易日被现有入场规则判为趋势转弱，或股票名称出现 ST/退市标记 |
| 观察到期 | 已观察至少五个完整交易日，当前仍未满足可介入条件，且判断所需数据完整 |
| 待复核 | 日线异常、取数失败、个股日线落后于大盘或大盘同日数据暂缺；不根据接口失败淘汰 |

当前入场结构模块只允许符合条件的「回踩上行 M20」进入买入候选；放量突破前高在现有规则中只作观察。严格选股命中、513 已确认、连续涨停均不能单独替代入场条件。

指标选股另外标记「涨停缩量加速」：以最近完整日线相对前一交易日接近对应板块涨停幅度，且当日成交量不超过此前 5 日平均量的 80% 为识别条件。该标记只用于风险降级和提示「不追高」，不会改变严格/宽松命中，也不会绕过回踩上行 M20、大盘过滤和盘中承接条件；回落后仍须重新完成现有入场复核。

候选每日重新验证，结构消失即降回观察；满五日仍未就绪则到期退出。候选结构保持有效时可继续留池。候选同时给出已有入场模块的失效参考价和失效规则。

显示的 0–4 项是检查项满足数：M20 上行、缩量、入场结构允许、大盘过滤通过；不是收益概率。价格为最近已复核交易日收盘价，不是盘中买入报价。功能不执行交易。

## 交易日与数据保护

- 使用真实日线日期计数，盘中排除当日未完成 K 线；同日重复扫描、周末、节假日沿用同一根日线时不增加天数。
- 不要求每天再次命中原来的金叉或低位条件。未进入本轮扫描范围、暂停交易或网络异常不会被当作「连续缺席」淘汰。
- 补做历史复核时，逐日只使用截至该日的个股和大盘数据，避免用后来的走势判断早先日期。
- 已淘汰/到期记录继续保留；至少出现五根新的完整日线且重新命中选股后，才开始新一轮观察。最多保留最近五轮历史摘要与记录。
- 不把选股页面沿用的旧结果当成新命中灌入观察池。

## 文件

- `screen_observation_state.json`：独立持久化状态，通过临时文件原子替换；保存失败会显示错误，不把未保存状态当成成功。
- `_screen_observation.txt`：可阅读的完整观察报告，含逐日复核记录。

状态文件损坏时显示错误并保留原文件，不静默清空覆盖。原有自选股、持仓和选股结果文件继续使用各自的存储。

## 盘中买点提醒

观察池中的股票即使没有加入持仓或自选股，也会独立检测买点。检测时段设为工作日 09:35–11:30、13:00–14:57，后台约每 60 秒检查一轮；发生取数或发送错误后等待 120 秒再试。应用启动后的首轮检查先复核完整日线，再开始盘中采样。

触发提醒需要同时满足：

1. 股票仍在观察池中，已有至少两个完整交易日的有效观察记录，日线复核日期与获取的最新完整日线一致。
2. 用实时价格、当日高低价和成交量重新计算现有入场结构，确认回踩上行 M20、缩量且现价重新站在 M20 上方。盘中量比按已交易分钟折算，午间休市时间不计入。
3. 同日实时上证指数仍在其 M20 上方；不沿用昨天的指数状态代替当前行情。
4. 至少三次不同时间的有效行情与资金流采样，行情和资金采样都跨越至少 120 秒。相邻采样不超过 180 秒；价格相对上一采样下跌超过 0.1% 会重新开始确认，最后一次价格也不能低于本轮首次价格。
5. 平台个股分钟资金净流入连续为正，使用现有方向判定门槛 `>0.01亿元`。每次需要新的资金数据时间戳，行情与资金数据均不得超过 150 秒；缺失、过期、净流出或不满足结构条件时重新观察。
6. 不在涨停附近：复用项目按代码区分的普通股票涨停幅度，以昨收估算涨停价并四舍五入到分，现价达到该价的 99.5% 或以上就拦截。这是保守的价格过滤，不是盘口封单或可成交性确认。触及该区域会清空本轮样本；之后回落也必须重新满足结构、资金和至少三次跨两分钟确认，才可发送新提醒。拦截不消耗当天提醒次数，也不单独淘汰股票。

这表示量价与平台资金口径出现承接迹象，不代表能识别具体买方，也不保证上涨或能成交。日线候选和盘中提醒分开记录；盘中采样不会增加完整交易日数量或伪装成收盘确认。新提醒策略版本为 `observation-pullback-v2`，事件证据保存估算涨停价及缓冲比例；旧提醒保留为历史记录。

发送方式为现有系统通知、提示音和置顶横幅，包含股票名称/代码、现价、M20、折算量比、资金证据及失效参考价。已有风险横幅显示时保留原横幅，买点仍可通过系统通知查看。

同一股票每天最多成功提醒一次，成功发送后将 `last_entry_alert` 写入观察池状态；正常落盘后重启不会重复提醒。发送失败不标为已提醒，下一轮仍可重试。若发送成功但状态文件写入失败，会显示错误，本次运行仍避免重复发送。菜单和完整报告中可以查看最近提醒时间、价格和触发依据。
