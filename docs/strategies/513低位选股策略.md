# 513 低位选股策略 · 详细说明

> 对应代码：`five_one_three.py`（判定核心）+ `stock_menubar.py`（扫描调度与菜单展示）
> 对应 Android 版：`analysis/FiveOneThreeScreener.kt`（逻辑逐条对齐，差异见文末）
> 用例：`tests/test_five_one_three.py`

---

## 一、策略思想

「513」是三个数字的缩写：**5 连阳 → 1 根倍量阳 → 3 天缩量**，对应主力建仓→试盘→洗盘的经典节奏：

```
5 连阳（悄悄爬升）→ 倍量阳（放量表态）→ 3 天缩量（回踩不破）→ 形态确认
```

它找的是**低位趴了很久、刚开始温和吸筹、然后放量启动、再缩量回踩**的股票。
这是一条量价形态规则，**不涉及基本面，也不构成买卖建议**。

## 二、三阶段与显示

| 阶段 | 触发条件 | 菜单显示 | 进度示例 |
|---|---|---|---|
| 观察中 | 5 连阳刚走完（第 5 根 = 最近一个完整交易日） | `5连阳观察` | `5连阳 5/5｜倍量阳 0/1｜缩量确认 0/3` |
| 等待确认 | 倍量阳出现，缩量确认不足 3 天 | `等待3天缩量` | `5连阳 5/5｜倍量阳 1/1｜缩量确认 2/3` |
| 形态已确认 | 3 天缩量全部合格 | `形态已确认` | `5连阳 5/5｜倍量阳 1/1｜缩量确认 3/3` |

榜单排序：**已确认 → 等待确认 → 观察中**，同阶段按**近 60 日涨幅低者优先**（更「低位」），再按名称。

「观察中」是转瞬即逝的状态：5 连阳的第 5 根不是最新完整交易日时，不再显示观察中
（次日走出倍量阳则升级；收阴/横盘则整只股票从名单消失，不保留失败记录）。

## 三、判定流程与参数

### 第 0 步：前置过滤（任一命中即淘汰）

| 条件 | 阈值 | 含义 |
|---|---|---|
| 股票名称含 ST | 排除 | 风险标的不做形态 |
| 完整日线数量 | ≥ 60 根 | 数据不足不判 |
| 近 60 日涨幅 | ≤ +30% | 已经涨过的不要 |
| 60 日区间位置 | < 85%（现价在高低区间的分位） | 还在高位的不要 |

> 区间位置 = (现价 − 60日最低) ÷ (60日最高 − 60日最低)。
> 涨幅和位置都是「低位」过滤：策略只做低位启动，不做追高。

### 第 1 步：5 连阳（观察中）

连续 5 个交易日，每根都满足：

| 条件 | 阈值 | 为什么 |
|---|---|---|
| 收阳线 | 收盘 > 开盘 | 连续收红 |
| 单日涨幅 | **1% ~ 3%** | 只要小阳线；不要大阳（排除游资拉板），也不要爬不动 |
| 单日成交量 | ≤ 20日基线均量 × **1.8** | 不许突然放量（放量说明不是悄悄吸筹） |
| 5 日均量 | ≥ 20日基线均量 × **0.65** | 也不能缩得太厉害（无人问津不算吸筹） |
| 收盘 vs 5日线 | **收盘 ≥ MA5（无容差）** | 贴着均线爬、不破位 |
| 均线趋势 | 窗口末日 MA5 ≥ 首日 MA5 | **5 日线必须走高**，拒绝「阳线但重心下移」的假形态 |

> 20 日基线 = 5 连阳窗口**之前 20 个交易日**的均量（不含窗口自身）。
> 窗口前没有任何历史 K 线时**直接判不合格**（无基线就无法验证「量能温和」）。

### 第 2 步：倍量阳（启动信号）

5 连阳的**下一个交易日**必须满足：

| 条件 | 阈值 | 为什么 |
|---|---|---|
| 收阳线 | 收盘 > 开盘 | 启动日要表态 |
| 量能 | ≥ 前一日成交量 × **2.0** | 「倍量」的字面意思：资金明确进场 |
| 收盘 vs 5日线 | 收盘 ≥ MA5（无容差） | 站上均线 |
| 上影线 | (最高−收盘)/最高 ≤ **6%** | 没冲高回落 |

### 第 3 步：3 天缩量（确认阶段）

倍量阳之后的 **3 个交易日**，每天都满足：

| 条件 | 阈值 | 为什么 |
|---|---|---|
| 量能递减 | 当日量 < 前一日量 **且** < 倍量阳当日量 | 洗盘缩量，不是放量出货 |
| 不破启动位 | 收盘 ≥ 倍量阳的**开盘价** | 回踩不破关键位（最重要的一条） |
| 振幅收敛 | (最高−最低)/前一日收盘 ≤ **5%** | 小阴小阳洗盘，不是巨震出货 |

**破坏即作废**：3 天里任何一天不合格，该形态整体跳过（不回退为 1/3、2/3 的部分形态，
除非确认天数走完且全部合格——例如只披露了 2 天且 2 天都合格，显示「等待确认 2/3」）。

## 四、阶段推进与候选选择

- 扫描时在 120 天日线里**逐个位置回溯**「从这天起算 5 连阳」，取**最后一个有效候选**（最近一次形态）。
- 5 连阳之后没走出倍量阳（次日收阴/横盘）→ 该候选直接跳过，名单上看不到。
- 行相邻即视为交易日相邻（数据缺行/脏行会被过滤后拼接，正常数据不受影响）。

## 五、只用完整交易日（关键设计）

判定**排除当日未完成 K 线**（`today` 参数）：

- 盘中正在走的第 3 根缩量哪怕看起来要成，也只显示「等待确认 2/3」，**不提前判确认**；
- 防止用盘中未定型的 K 线得出「已确认」的假信号。

## 六、扫描机制（macOS 版）

| 项 | 设计 | 原因 |
|---|---|---|
| 扫描范围 | **全部沪深 A 股**（新浪分页，最多 100 页 × 80） | 513 是形态扫描，不该只盯成交前 200 |
| 深扫频率 | **每天一次**（当日首次扫描自动触发） | 513 只依赖完整交易日，盘中结果不变；akshare 逐股取日线，全市场一次约数十分钟，逐槽重扫有被限流风险 |
| 盘中半小时槽 | 只快扫成交前 200（严格/宽松需要当日 K 线），513 名单**合并刷新本次扫过股票的现价** | 现价不落灰，全市场命中不丢 |
| 严格/宽松策略 | 仍只算成交前 200 | 与 513 独立，口径不变 |

### 漏斗统计（菜单展示）

```
全市场扫描 N 只｜有效日线 N 只
历史5连阳 N 只｜当前5连阳 N 只
倍量阳确认 N 只｜完整513确认 N 只
```

| 指标 | 含义 |
|---|---|
| 全市场扫描 | 本轮扫到的股票数 |
| 有效日线 | 完整日线 ≥ 60 根的股票数 |
| 历史5连阳 | 序列内**出现过** 5 连阳（不管之后走没走出来） |
| 当前5连阳 | 最近一个完整交易日**正处于** 5 连阳 |
| 倍量阳确认 | 命中项中处于「等待确认」阶段的数量 |
| 完整513确认 | 命中项中「形态已确认」的数量 |

「历史5连阳」比「当前5连阳」多是正常的：多数形态走完 5 连阳后没走出倍量阳就熄火了。

## 七、参数总表

| 参数 | 值 | 用途 |
|---|---|---|
| MIN_HISTORY_DAYS | 60 | 最少完整日线数 |
| FIVE_DAYS | 5 | 连阳天数 |
| CONFIRMATION_DAYS | 3 | 缩量确认天数 |
| BASELINE_DAYS | 20 | 量能基线窗口 |
| MOVING_AVERAGE_DAYS | 5 | 均线周期 |
| MIN_SINGLE_GAIN / MAX_SINGLE_GAIN | 1% / 3% | 单日涨幅带 |
| MAX_GAIN_60D_PCT | 30% | 60 日涨幅上限 |
| MAX_RANGE_POSITION | 85% | 60 日区间位置上限 |
| MIN_OBSERVATION_VOLUME_RATIO | 0.65 | 5 日均量/基线 下限 |
| MAX_OBSERVATION_VOLUME_RATIO | 1.8 | 单日量/基线 上限 |
| DOUBLE_VOLUME_RATIO | 2.0 | 倍量阳量能倍数 |
| MAX_PULLBACK_RATIO | 6% | 倍量阳上影线上限 |
| MAX_CONFIRMATION_AMPLITUDE | 5% | 确认日振幅上限 |

## 八、边界行为（实测/回归测试覆盖）

1. **无量能基线 → 直接拒绝**：5 连阳窗口前没有任何历史时，量能约束无从验证，判不合格
   （Android 版此处会静默跳过量能检查，macOS 收紧，见差异表）。
2. **确认中断 → 整形态作废**：确认日放量/破位/巨震 → 跳过该候选，不降级保留。
3. **多形态共存 → 取最近**：同一股票历史上多次走出 513 时，名单只显示最近一次有效形态。
4. **当日 K 线永不参与判定**：包括倍量阳与确认日。

## 九、与 Android 版的差异

| 项 | Android | macOS |
|---|---|---|
| 5 连阳窗口前无量能基线 | 空基线 NaN 比较失效，量能约束被跳过 | **直接判不合格**（更严，防巨量假形态） |
| 513 扫描节奏 | 每个半小时槽全市场重扫 | 每天全市场深扫一次 + 盘中快扫合并现价（513 盘中不变，避免 akshare 限流） |
| 其余规则 | —— | 逐条一致（过滤阈值、三阶段、破坏即作废、排序、漏斗统计） |

## 十、使用与限制

- 入口：菜单栏 → 📈 指标策略 → 「513形态」区段。
- 命中只是**量价形态符合**，不代表主力建仓或必然上涨；需结合基本面、市场环境和止损纪律判断。
- 数据源为新浪/akshare 日线（前复权口径）；除权股的支撑/压力是复权价。
- 本策略与所有输出均不构成投资建议。
